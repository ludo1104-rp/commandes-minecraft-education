# Commandes Minecraft Education

Une appli web pour trouver vite la bonne commande de chat dans **Minecraft Education**, la copier et la coller dans le jeu.

Pensée pour une classe : des phrases courtes, un style « Minecraft » ou « Simple », trois tailles de texte et une lecture à voix haute.

## Ce qu'elle fait

- **150 commandes**, rangées par thème : temps et météo, déplacements, objets, construction, règles du monde, classe, messages, effets, PNJ et personnages, créatures.
- **Recherche par mot-clé** en français (« voler », « nuit », « PNJ »…), qui accepte les petites fautes.
- **Commandes prêtes à copier** : on choisit dans des listes (animal, effet, bloc, « Pour qui ? »…), puis on clique sur « Copier ».
- **★ Pour créer un monde** : les commandes utiles à l'enseignant qui prépare une activité.
- **Je découvre une commande** : une commande au hasard, pour apprendre.
- **Aide pas à pas** : comment écrire une commande dans le chat.

## Utiliser l'appli

Ouvrir la page en ligne (lien GitHub Pages ci-dessous), ou télécharger `index.html` et l'ouvrir dans un navigateur. Aucune installation, aucun compte.

Dans Minecraft : ouvrir le chat avec **T**, coller avec **Ctrl + V** (Cmd + V sur Mac), puis appuyer sur Entrée. Les commandes « Enseignant » demandent les triches activées.

## Fiabilité

Chaque commande, et chaque choix des listes, est vérifiée avec les données officielles de Mojang pour Minecraft Bedrock 1.26.30 (dépôt `Mojang/bedrock-samples`). Les commandes propres à Education viennent de l'aide officielle de Minecraft Education. Elles n'ont pas encore toutes été testées en jeu : des erreurs peuvent survenir.
